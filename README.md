# CloudVault File Manager
A beginner-friendly student portfolio demo for cloud file management.

## Features
- Demo file list with search and delete
- Simulated upload records saved in localStorage
- Basic educational security checklist
- Responsive design

## AWS connection
This project is designed around concepts such as Amazon S3 for file storage and IAM for access management. This version does **not** connect to AWS and is not production-ready.

## Run locally
Download the files and open `index.html` in a browser.

## Limitations
No real authentication, file uploads, encryption, or cloud storage is included. Do not use real personal or company data.
